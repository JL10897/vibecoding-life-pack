# Search Strategies for Different Gap Types

## Empirical Claim Support

**Goal**: Find papers with experimental results supporting your claim

### Query Formulation
- Include the phenomenon + "experimental" or "empirical"
- Add domain terms (NLP, vision, etc.)
- Include metric names if claiming performance

### Examples
| Claim | Good Query |
|-------|------------|
| "LLMs can do X" | "large language models X empirical evaluation" |
| "Method Y improves Z" | "Y improves Z benchmark results" |
| "X correlates with Y" | "correlation X Y experimental study" |

### Where to Look in Papers
- Abstract (for quick relevance check)
- Results section (for specific numbers)
- Tables (for comparative data)

---

## Methodological Claims

**Goal**: Find papers that establish or validate a technique

### Query Formulation
- Method name + "analysis" or "study"
- Include "best practices" or "guidelines"
- Add application domain

### Examples
| Claim | Good Query |
|-------|------------|
| "Technique X is standard" | "X technique survey best practices" |
| "Approach Y is preferred for Z" | "Y approach Z comparison study" |

### Where to Look in Papers
- Related work (for established practices)
- Methodology section (for technique details)

---

## Theoretical/Conceptual Claims

**Goal**: Find papers that define or establish concepts

### Query Formulation
- Concept name + "definition" or "framework"
- Include "theory" or "foundations"
- Look for survey/review papers

### Examples
| Claim | Good Query |
|-------|------------|
| "X is defined as..." | "X definition framework" |
| "Y concept was introduced by..." | "Y concept origins seminal" |

### Where to Look in Papers
- Introduction (for definitions)
- Background section (for established concepts)

---

## Statistical/Quantitative Claims

**Goal**: Find papers with specific numbers or statistics

### Query Formulation
- Include the statistic type
- Add "benchmark" or "evaluation"
- Include dataset names if relevant

### Examples
| Claim | Good Query |
|-------|------------|
| "X achieves Y% accuracy" | "X accuracy benchmark evaluation" |
| "Dataset contains N samples" | "dataset statistics analysis" |

### Where to Look in Papers
- Tables (exact numbers)
- Results paragraphs (with context)

---

## Related Work Gap Filling

**Goal**: Find seminal or important prior work

### Query Formulation
- Use "survey" or "review" + topic
- Include "related work" + your method category
- Look for highly-cited papers

### Examples
| Gap | Good Query |
|-----|------------|
| Missing foundational work | "topic survey comprehensive review" |
| Missing recent work | "topic 2023 2024 state of the art" |

## Zotero-Specific Tips

### Semantic Search Queries
- Use natural language, not keywords
- Describe what you're looking for conceptually
- Include the purpose (e.g., "papers showing that X leads to Y")

### Filtering Results
- Check publication year for recency
- Prefer peer-reviewed over preprints for established claims
- Look at citation count for importance

### When Zotero Fails
1. Query too specific → broaden terms
2. Query too broad → add constraints
3. Paper not in library → use WebSearch, then add to Zotero

## Quote Extraction Tips

### Good Quote Locations
- First/last sentence of Results paragraphs
- Table captions with numbers
- Abstract claims with evidence
- Conclusion key findings

### Quote Selection Criteria
- Self-contained (understandable alone)
- Contains specific evidence
- Directly relevant to your claim
- Not hedged excessively

### Red Flags
- "may", "might", "could" without evidence
- References to other papers for the claim
- Speculative future work statements
